Here is a complete technical specification and architectural blueprint for building a hyper-fast, low-footprint Windows 11 launcher.

---

### System Architecture & Tech Stack

* **Runtime:** .NET 8 / C# 12 compiled via **Native AOT** (`<PublishAot>true</PublishAot>`).
* **Framework:** Windows Forms (WinForms).
* **Process Lifecycle:** System Tray application (`NotifyIcon`). Stays resident in RAM (~10–15 MB).
* **Activation:** Global Hotkey (`RegisterHotKey`) or Mouse Trigger $\rightarrow$ Unhide window at cursor coordinate ($X, Y$) in $< 2\text{ms}$.
* **Glass Composition:** `dwmapi.dll` Desktop Acrylic via `DwmSetWindowAttribute`.
* **Layout Model:** Hover-Split Panel (Left track: Categories; Right grid: Action Buttons). Zero click-delays on hover.

### 2. Phase 1: Native DWM Glass Interop Layer

Standard WinForms title bars and borders must be disabled (`FormBorderStyle.None`). We then instruct the Windows Desktop Window Manager (DWM) to extend the frame and apply **Desktop Acrylic** (`DWMSBT_TRANSIENTWINDOW`).

#### `GlassInterop.cs` (Native AOT Compatible)

```csharp
using System;
using System.Runtime.InteropServices;

public static partial class GlassInterop
{
    public enum DWMWINDOWATTRIBUTE : uint
    {
        DWMWA_USE_IMMERSIVE_DARK_MODE = 20,
        DWMWA_SYSTEMBACKDROP_TYPE = 38
    }

    public enum DWMSBT : uint
    {
        DWMSBT_DISABLE = 1,
        DWMSBT_MAINWINDOW = 2,      // Mica
        DWMSBT_TRANSIENTWINDOW = 3, // Desktop Acrylic
        DWMSBT_TABBEDWINDOW = 4     // Acrylic Tabbed
    }

    [StructLayout(LayoutKind.Sequential)]
    public struct MARGINS
    {
        public int cxLeftWidth;
        public int cxRightWidth;
        public int cyTopHeight;
        public int cyBottomHeight;
    }

    [LibraryImport("dwmapi.dll")]
    public static partial int DwmExtendFrameIntoClientArea(IntPtr hWnd, ref MARGINS pMarInset);

    [LibraryImport("dwmapi.dll")]
    public static partial int DwmSetWindowAttribute(IntPtr hwnd, DWMWINDOWATTRIBUTE attribute, ref uint pvAttribute, uint cbAttribute);

    public static void EnableAcrylic(IntPtr hwnd)
    {
        // 1. Force dark mode window frame
        uint darkMode = 1;
        DwmSetWindowAttribute(hwnd, DWMWINDOWATTRIBUTE.DWMWA_USE_IMMERSIVE_DARK_MODE, ref darkMode, sizeof(uint));

        // 2. Extend sheet of glass across whole client rect
        var margins = new MARGINS { cxLeftWidth = -1, cxRightWidth = -1, cyTopHeight = -1, cyBottomHeight = -1 };
        DwmExtendFrameIntoClientArea(hwnd, ref margins);

        // 3. Enable Desktop Acrylic backdrop
        uint backdropType = (uint)DWMSBT.DWMSBT_TRANSIENTWINDOW;
        DwmSetWindowAttribute(hwnd, DWMWINDOWATTRIBUTE.DWMWA_SYSTEMBACKDROP_TYPE, ref backdropType, sizeof(uint));
    }
}

```

### 3. Phase 2: Custom Glass Controls Engine

Standard GDI+ controls strip pixel alpha channels, rendering black boxes over DWM Acrylic. Every hover item or menu header **must** draw using double-buffering and explicit GDI+ path rendering with anti-aliasing.

#### `GlassButton.cs`

```csharp
using System;
using System.Drawing;
using System.Drawing.Drawing2D;
using System.Drawing.Text;
using System.Windows.Forms;

public class GlassButton : Control
{
    public bool IsSelected { get; set; }
    private bool _isHovered;

    public GlassButton()
    {
        SetStyle(ControlStyles.SupportsTransparentBackColor |
                 ControlStyles.OptimizedDoubleBuffer |
                 ControlStyles.AllPaintingInWmPaint |
                 ControlStyles.UserPaint, true);
        
        BackColor = Color.Transparent;
        DoubleBuffered = true;
    }

    protected override void OnMouseEnter(EventArgs e) { _isHovered = true; Invalidate(); }
    protected override void OnMouseLeave(EventArgs e) { _isHovered = false; Invalidate(); }

    protected override void OnPaint(PaintEventArgs e)
    {
        Graphics g = e.Graphics;
        g.SmoothingMode = SmoothingMode.AntiAlias;
        g.TextRenderingHint = TextRenderingHint.ClearTypeGridFit; // Crucial: Fixes black halos around text

        var rect = new Rectangle(0, 0, Width - 1, Height - 1);

        // Render hover state (10% translucent white) or active selection state (25% translucent white)
        if (_isHovered || IsSelected)
        {
            int alpha = IsSelected ? 50 : 25;
            using var brush = new SolidBrush(Color.FromArgb(alpha, 255, 255, 255));
            using var path = CreateRoundedPath(rect, 6);
            g.FillPath(brush, path);
        }

        // Text rendering
        Color textColor = _isHovered || IsSelected ? Color.White : Color.FromArgb(200, 200, 200);
        TextRenderer.DrawText(g, Text, Font, rect, textColor, 
            TextFormatFlags.Left | TextFormatFlags.VerticalCenter | TextFormatFlags.LeftMargin);
    }

    private static GraphicsPath CreateRoundedPath(Rectangle r, int radius)
    {
        GraphicsPath path = new GraphicsPath();
        int d = radius * 2;
        path.AddArc(r.X, r.Y, d, d, 180, 90);
        path.AddArc(r.Right - d, r.Y, d, d, 270, 90);
        path.AddArc(r.Right - d, r.Bottom - d, d, d, 0, 90);
        path.AddArc(r.X, r.Bottom - d, d, d, 90, 90);
        path.CloseFigure();
        return path;
    }
}

```

### 6. Phase 5: Instant Spawn & Shell Execution

To eliminate cold-start lag completely, the application boots directly to the system tray. Pressing the global hotkey repositions the pre-rendered window handle (`HWND`) under the cursor in `< 2ms`.

```csharp
public partial class LauncherForm : Form
{
    protected override void OnLoad(EventArgs e)
    {
        base.OnLoad(e);
        
        // Form styling settings
        FormBorderStyle = FormBorderStyle.None;
        StartPosition = FormStartPosition.Manual;
        ShowInTaskbar = false;
        BackColor = Color.Black; // Must be dark background for Acrylic blend

        // Apply Windows 11 Glass
        GlassInterop.EnableAcrylic(this.Handle);
    }

    public void ShowAtCursor()
    {
        Point cursor = Cursor.Position;
        
        // Keep window within display bounds
        Screen screen = Screen.FromPoint(cursor);
        int x = Math.Min(cursor.X, screen.WorkingArea.Right - Width);
        int y = Math.Min(cursor.Y, screen.WorkingArea.Bottom - Height);

        Location = new Point(x, y);
        Show();
        Activate();
    }

    protected override void OnDeactivate(EventArgs e)
    {
        base.OnDeactivate(e);
        Hide(); // Auto-dismiss menu when focus is lost
    }

    public static void ExecuteScript(string path, string args)
    {
        var startInfo = new System.Diagnostics.ProcessStartInfo
        {
            FileName = path,
            Arguments = args,
            UseShellExecute = true // Detaches process so launcher doesn't block
        };
        System.Diagnostics.Process.Start(startInfo);
    }
}

```

### Critical Implementation Checklist & Gotchas

1. **The WinForms Dark Background Trap:** You **must** set `Form.BackColor = Color.Black` (or a near-black dark grey) before enabling DWM Acrylic. If you leave `BackColor` as default control grey, the Acrylic compositor will bleed bright white tones into your dark mode UI.
2. **Font Alpha Artifacts:** Always set `g.TextRenderingHint = TextRenderingHint.ClearTypeGridFit` inside `OnPaint`. Default GDI text rendering deletes the 8-bit alpha channel of underlying pixels, creating dark fuzzy boxes around letters when painted over glass.
3. **Focus Loss Auto-Dismiss:** Listen to the `Form.Deactivate` event and call `Hide()`. This ensures the context menu behaves identically to a native Windows popup (clicking anywhere outside destroys focus and hides the menu).
4. **ShellExecute Path Resolution:** Always pass `UseShellExecute = true` when launching external scripts. This ensures relative paths (like `./scripts/qwen.ps1`) resolve via the OS environment shell and don't stall your launcher window thread.
5. **No Dynamic Assembly Loaders:** Never use `Assembly.Load()` or dynamic reflection calls when adding third-party plugins if you want to keep the `<PublishAot>true</PublishAot>` flag enabled.
